# Style A provisoire — publication sur main

Le 16 novembre 2026, le propriétaire a demandé de pousser toute la passe UX avec le style A pour le moment. Le design ne le satisfait pas encore complètement : une révision artistique ultérieure reste prévue.

Arcade TV 1993 devient le défaut des écrans de création et de management, sans paramètre d’URL. La bannière de comparaison disparaît du parcours normal. La variante B reste disponible via `?ux-style=almanac` pour les travaux ultérieurs. Les styles sont centralisés dans `src/ui/managementTheme.css`, le défaut dans `managementTheme.ts` ; aucune donnée de carrière ne dépend de ce choix.

Cette publication inclut les parcours guidés, les liens directs contrats/offres, les reçus de décision, les cartes d’effectif, la pagination du marché, le nouveau demi-terrain pédagogique et les preuves de régression de la passe V3. La restauration JSON reste différée comme expliqué dans UX_SAVE_RESTORE_FOLLOWUP.md.

Les nombres de notes/attributs sont contrastés sur les panneaux ivoire. Le moteur, Phaser, le store, les sprites et les 30 identités de franchises sont inchangés.

Les vérifications finales du style par défaut sont conservées dans `docs/ux/style-a`. Elles complètent les preuves V3 sous `docs/ux/logs`.
